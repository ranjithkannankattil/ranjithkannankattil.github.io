```

writings.html           Writings archive — 365 posts, search + tag filters

publications.html       Books + academic publication
radio.html              Live Malayalam radio
movies.html             Movies: fuzzy film search, all ratings, similar-film rows, people pages; plus the
                        owner-only diary, watchlist and dashboard (js/movies.js, js/movies-log.js,
                        js/movies-dash.js, css/movies.css; settings in js/movies-config.js).
                        Data from the movies-api Worker (worker/movies-api.js — setup in worker/README.md);
                        the private log is in Firestore under movielog/{owner uid}/ (rules in firestore.rules)
productivity/           Productivity tools hub (index.html) + one page per tool
  meeting.html          Tool 01: meeting time finder (js/tool-meeting.js, css/tool-meeting.css)
                        City catalogue + default seven: js/cities.js (add cities there)
  raci.html             RACI matrix builder (js/tool-raci.js, css/tool-raci.css)
  pdf.html              PDF toolkit (js/tool-pdf.js, css/tool-pdf.css; pdf-lib + PDF.js in js/vendor/)
  passport.html         Passport photo maker (js/tool-passport.js, css/tool-passport.css)
  units.html            Oil & gas unit converter (js/tool-units.js, css/tool-units.css)
  map.html              Map colourer (js/tool-map.js, css/tool-map.css); boundary data in
                        assets/maps/ (Natural Earth, India point of view; a1/<ISO3>.json per country)
productivity.html       Redirect from the old address (keeps meeting-finder links working)
js/tools.js             Tool registry + groups: builds the grouped, searchable hub, and each tool
                        page's breadcrumb, "All tools" switcher and previous / next links
css/productivity.css    Shared styles for the hub and every tool page
feed.xml                RSS feed (latest 50 writings, static — regenerate manually)
CNAME                   Custom domain file for GitHub Pages (ranjithkb.com)

assets/photos/          Photography page images + Home hero image
assets/books/           Book covers + downloadable PDFs
```

No build step. Plain HTML/CSS/JS — GitHub Pages serves it as-is.

## Deploy to GitHub Pages
1. Repo `ranjithkannankattil.github.io` already exists per your setup — push
   these files to `main`:
   ```
   git add .
   git commit -m "Update site"
   git push
   ```
2. Settings -> Pages should already be configured (Deploy from branch -> main / root).
3. Custom domain: the `CNAME` file in this package contains `ranjithkb.com`.
   Confirm in Settings -> Pages that the custom domain field also shows
   `ranjithkb.com` and that "Enforce HTTPS" is checked once DNS is verified.
   If your Namecheap DNS was still propagating for the `www` subdomain last
   you checked, worth re-verifying it's fully resolved now.

## Updating content

New writing: add an entry to the `POSTS` array in `js/posts.js` — copy an
existing object's shape (slug, title_ml, title_en, date, source, blog, tags,
body array, source_url). After adding posts, regenerate `feed.xml` if you
want the RSS feed to include them (ask me — it's a small script).

Retagging: current tags were generated by a heuristic script (structural
poem/prose detection + Malayalam keyword matching for themes). Not
literary-quality judgment — treat any single post's tags as a first pass, and
edit `tags` arrays directly in `js/posts.js` if something's off.

Facebook post links: `source_url` is empty for all 242 Facebook posts —
the export didn't capture permalinks. Any post you add a `source_url` to will
automatically show a "Read original" link on the archive and post page.

New photos: drop files in `assets/photos/`, add a `.frame` block in
`photography.html` following the existing pattern.

New book/publication: add a `.book-card` block in `publications.html`
following the existing pattern (cover image, meta line, description, links).

## Design notes
- Each section carries its own accent colour via `[data-section]` in
  `css/style.css`: home (blue), cv (steel blue), photography (brick rust),
  writings (ochre-gold), publications (wine).
- The diamond divider is reused from the Hridyaksharangal poster system.
- Malayalam text uses the Manjari typeface throughout.
- Byline convention: "Ranjith" on Home/Photography, "Ranjith K B" on CV,
  "Ranjith Kannankattil" on Publications/literary content.

## Adding a productivity tool
1. Add an entry to `window.TOOLS` in `js/tools.js` (id, name, short, href, blurb, meta).
2. Copy `productivity/meeting.html` to `productivity/<id>.html`; keep the header,
   `<main data-tool="<id>">` and `<div data-tool-nav>`, replace the `<section>`.
3. Put the tool's code in `js/tool-<id>.js` and `css/tool-<id>.css`.
4. Add it to the PRODUCTIVITY list in `js/nav.js` so the site's Tools menu lists it.
5. Add a line to SECTIONS in `scripts/build_cards.py` for its link-preview card, and a sitemap entry.
The hub card, the switcher and previous / next links update by themselves.
